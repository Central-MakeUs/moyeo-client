# Colors

`_app/globals.css`의 `@theme` / `@theme inline`에 정의된 color 토큰입니다.
값의 단일 소스는 `globals.css`입니다.

> 컴포넌트에서는 hex를 하드코딩하지 말고 `bg-primary`, `text-neutral-900`처럼 토큰 기반 Tailwind class를 사용합니다.

## Brand

<ColorPalette>
  <ColorItem title="primary" subtitle="서비스 대표 색상" colors={{ primary: '#f43630' }} />
</ColorPalette>

## Common

디자인 시스템 전역에서 쓰이는 단일 색상입니다.
white, black은 별도 토큰 없이 Tailwind 기본값(`bg-white`, `bg-black` / `text-white`, `text-black`)을 사용합니다.

<ColorPalette>
  <ColorItem title="white" subtitle="Tailwind 기본 · bg-white" colors={{ white: '#ffffff' }} />
  <ColorItem title="black" subtitle="Tailwind 기본 · bg-black" colors={{ black: '#000000' }} />
  <ColorItem
    title="opacity-40"
    subtitle="--color-opacity-40 · 오버레이"
    colors={{ 'opacity-40': '#00000066' }}
  />
</ColorPalette>
