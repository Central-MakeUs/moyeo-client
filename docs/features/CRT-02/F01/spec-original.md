# Draggable Calendar 기능 정의서 (spec-original)

## 기능 개요

캘린더에서 **드래그**와 **셀 탭(토글)**을 통해 날짜를 선택/해제할 수 있는 재사용 캘린더 인터랙션.
CRT-02(모임 생성 - 일정 정하기)의 조율 날짜 입력에 사용되며, 산출물은 모임 생성 payload의 `scheduleCandidateDates`가 된다.

## 기능 요구사항

### 날짜 선택/해제

- 드래그 시작 셀의 상태에 따라 **이번 드래그의 동작이 하나로 고정**된다(페인트 방식).
  - 시작 셀이 **미선택**이면 → 드래그 대상 셀을 모두 **선택** 상태로 변경한다.
  - 시작 셀이 **선택**이면 → 드래그 대상 셀을 모두 **해제** 상태로 변경한다.
  - (드래그 도중 셀마다 선택/해제가 뒤섞이지 않는다.)
- 드래그 대상 = **시작 날짜와 끝 날짜 사이의 연속된 모든 날짜**이다(날짜 순서 기준, 그리드 사각형 아님).
  - 예: `6/9 → 6/18` 드래그 시 6/9부터 6/18까지 연속 10일이 모두 대상이 된다.
- 각 날짜 셀은 드래그 외에 **단일 탭(토글)**로도 선택/해제할 수 있다.
- 비활성(오늘 이전) 셀은 선택 대상에서 제외되며, 드래그 범위에 포함되어도 건너뛴다.
- 최종 선택은 **날짜들의 집합**이며(연속 기간이라는 별도 의미는 없음), 저장 시 날짜 배열로 직렬화한다.

### 선택 범위 제한

- 선택 가능한 최대 기간은 **3주**이다(선택된 날짜의 min~max가 21일 이내).
- 3주를 초과하는 드래그를 시도할 경우 → **시작점 기준 3주 이내 셀까지만** 선택하고, 사용자에게 "3주 내만 선택 가능"을 안내한다. _(잠정 — PM 확정 필요)_

### 월 이동 / 경계

- 캘린더는 한 번에 한 달을 표시하며, **선택 상태는 월 이동 후에도 유지**된다.
- 한 번의 드래그 제스처는 **현재 보이는 달 안에서만** 유효하다(드래그 중 자동 월 넘김은 MVP 범위 밖).
- 월 경계를 넘는 선택은 "월 이동 후 이어서 선택"으로 처리한다.

### 도메인 제약 (CRT-02에서 주입)

컴포넌트 자체가 아니라 CRT-02 화면이 값으로 주입하는 규칙:

- 최대 선택 기간: 3주
- 오늘 이전 날짜 비활성 (오늘/서버 시간 기준)

### 출력 (Output)

- `scheduleCandidateDates: string[]` — 선택된 날짜의 배열, ISO `yyyy-MM-dd` 형식.
  - 예: `["2026-07-04", "2026-07-05"]`
  - 모임 생성 payload에 포함된다. (시간대 `availableStartTime` / `availableEndTime`은 별도 시간 피커(F03) 산출물)

## 비고

- 컴포넌트는 `web/src/shared/primitives/`의 캘린더 primitive 위에 구현한다.
- **3주 제한·비활성 규칙은 컴포넌트에 하드코딩하지 않고 prop으로 주입**한다
  (예: `maxRangeDays`, `isDateDisabled` 등) → 다른 화면에서도 재사용 가능하도록.
