## 컴포넌트 레퍼런스 이미지 (PM 제공)

- `list-item-confirmed-meeting`: 흰색 카드. 제목("CMC UT데이 (모여조)") + 캘린더 아이콘/일시 + 위치 아이콘/장소 + 우측 커버 썸네일.
- `avatar` / `avatar-group`: 원형 아바타 아이콘 여러 개 + 오버플로 시 "+N" 배지(빨간색). 다른 화면(스케줄 가능 인원 등)에서도 "회색(미참여)/빨간색(참여)" 아이콘 + "+N" 조합이 재사용되는 것으로 보임(예: "6/7명 가능" — 회색 아이콘 4개 + "+2" 배지).
- `Image-card-meeting`: 카드 상단의 커버 이미지 영역(빈 상태는 figma 체커보드 placeholder).
- `card-meeting`: 흰 카드. title, "🕐 마감 D-N" 배지, 커버 이미지, 하단에 avatar-group + "N/N 참여중" 텍스트.
- `dot` / `page-control`: 캐러셀 페이지 표시 점(활성 = 빨간 알약, 비활성 = 회색 점).
- FAB: 우하단 원형 빨간 버튼(+ 아이콘).

## PM 코멘트 (대화 중 확인)

- 이번 이슈 범위는 **위 mockup 화면 자체**다. 명세표(F01~F08)는 배경 참고 자료이며, F04(모달)·F05(공유 버튼)는 이번 범위가 아니다.
- FAB은 다른 브랜치/PR에 있을 수 있으나 지금은 신경 쓰지 말고 새로 구현. 나중에 PM이 합류/정리.
- 모임 목록 조회 API는 백엔드에 이미 존재. Orval(openapi) 재생성만 하면 됨.
- avatar-group 오버플로 규칙(정원 5명 초과 시 4개 아바타 + "+N" 배지) 및 아바타 정렬 규칙(회색/미참여 우선 표시)은 PM이 예시로 확정: `13/20 → 회회회회 +16`, `18/20 → 회회빨빨 +16`.
